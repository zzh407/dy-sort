设置（持久化保存）

开启后「加入 Emby」以博主目录为单位分流：超过上限的库不再追加，改建同名序号库（DY_瑜伽裤 → DY_瑜伽裤2 → DY_瑜伽裤3）。同一个目录不会拆到两个库。
DY_ 库的视频数超过该值就不再往里加；映射页会显示每个库的用量，超限库可点「整理」把放不下的目录整体迁到新库
/data 下混有其他媒体时，选择短视频所在子目录；换绑后索引自动重建
0 = 关闭；保存后立即生效，无需重启容器
填的是 /data 对应的 Emby 侧路径；传给 Emby 的博主目录 = 该路径/绑定子目录/博主ID。为空则用容器内实际路径
开启后可删除单个视频或整个博主目录（磁盘文件不可恢复，博主级删除会联动移出 Emby）。所有删除均有二次确认；关闭立即生效

图像识别

本地模型：首次识别会自动下载 CLIP ONNX（quantized 约 155MB）到下面的目录，之后完全离线推理，不需要 Ollama 之类的外部服务； 大模型：默认用智谱 GLM-4V-Flash（免费），只需填 API Key； 规则：只用 Emby 库名 / 博主名 / 视频名里的关键词。
CLIP 对同类细标签（包臀裙/半身裙/连衣裙）分辨力弱，大类明显更准；细标签仍保留在博主的 labels 里
放在 cache 卷里，容器重建/升级不会丢；下载后可以离线使用
国内默认走 hf-mirror；能直连时可以改成 https://huggingface.co
默认智谱（GLM-4V-Flash 免费）；也可填 OpenAI / DashScope / 火山方舟 / 本地 vLLM 的兼容地址
默认 glm-4v-flash（智谱免费图像理解）；也可换成 glm-5.3-flash、gpt-4o-mini、qwen-vl-max 等
格式「标签:关键词1,关键词2; 标签2:关键词」。用于本地识别匹配，也用于把模型输出的同义词归位到标准标签
识别结果只会落在这些标签里；默认 49 个，改完保存后立即生效
本地模型每张图只报最像的一个身材大类，按命中张数排序；默认 21 个
至少 10 个（素材不足时按实际数量）；「识别」页的快速识别用它，「全量识别」不看这个值
每次 1 张最准也最贵（抽 10 张 = 10 次请求）；合并成 2~5 张省请求但可能少判几张；并发别超过服务商限流
